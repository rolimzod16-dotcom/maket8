# Maket 8 — Interactive Floor Digital Twin

Интерактивный архитектурный MVP восьмого этажа.

## Возможности

- кликабельный 2D-план;
- 3D dollhouse/обзор;
- выбор и подсветка помещений;
- прогулка WASD + мышь;
- collision detection;
- мобильный джойстик и touch-look;
- fullscreen;
- WebXR при наличии VR-устройства;
- раздельные данные помещений, геометрия и материалы.

## Vercel

Репозиторий собирается как Next.js. Параметры заданы в `vercel.json`.
После `git push` в `main` Vercel сам выкатывает production.
